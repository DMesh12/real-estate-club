איך משיגים מפתח Gemini API?

כדי להשתמש בבינה המלאכותית (AI) באתר זה, נדרש מפתח אישי מגוגל. זה חינם ופשוט:

  1. כנסו לאתר Google AI Studio.
  2. התחברו עם חשבון ה-Google שלכם.
  3. לחצו על הכפתור הכחול הגדול Create API Key.
  4. העתיקו את הקוד הארוך שקיבלתם.
  5. הדביקו אותו בתיבת Gemini API Key בראש העמוד כאן.
